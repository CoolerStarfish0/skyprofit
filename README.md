# SkyProfit

A profile-aware Hypixel SkyBlock money-making advisor.

## Current status

This is the first frontend foundation. It includes the responsive dashboard shell, playstyle selector, and username input. Live SkyBlock profile, Bazaar, mayor, and recommendation integrations are not connected yet; the interface deliberately avoids inventing player stats or market opportunities.

## Run locally

This starter is a static site. Open `index.html` in a browser, or run a local static server:

```bash
npx serve .
```

## Planned integrations

- SkyBlock profile lookup and profile parsing
- Hypixel Bazaar market data and realistic order-fill estimates
- Current mayor, minister, perks, and event modifiers
- Method-specific gear, pet, equipment, and upgrade recommendations
- Flip tracking and user-approved assisted workflows

SkyProfit is an unofficial fan project and is not affiliated with Hypixel.
